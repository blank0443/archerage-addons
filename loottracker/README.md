## Loot Tracker

A simple addon for keeping track of item quantity count in inventory for farming loot.

### NOTE: Use command "/loottracker reset" to reposition the window if it unreachable/disappears. 

![Loot Tracker UI](https://raw.githubusercontent.com/blank0443/addon_assets/main/loot_tracker/main_window.png)

![Search Window](https://raw.githubusercontent.com/blank0443/addon_assets/main/loot_tracker/search_item.gif)

![Search Window](https://raw.githubusercontent.com/blank0443/addon_assets/main/loot_tracker/rotate_ui.gif)





Click on one of the slots to add/change an item to keep track of.

- Automatically hide UI buttons when not hovered.
- Keep track of item counts in inventory.
- Highlight tracked items when their count goes up.
- Easily hide the addon when not in use (X Button) or in Esc Menu (M:0/M:1)
- Search and scroll inventory items (Click on box slot)
- Remove a tracked item with right click.
- Reorder tracked items with right-click drag.
- Switch Between vertical or horizontal display (R Button)
- Resize the tracker window with corner handles.
- Show your loot drop rate bonus when available.
- Easily clear tracked items (C Button)
- Add/remove tracking slots via -,+ button.
- Save, overwrite, swap, and delete tracking sets (S).
- Keep track of mobs killed (K).
- Auto-open the kill counter when kills are recorded.
- Track player deaths in the kill counter.
- View kill session totals for kills, EXP, gold, damage, mana, distance, and loot.
- View combat details for DPS, healing, misses, and skills.
- Save kill sessions after loading screens.
- Browse kill session history.
- Open a saved kill session on the world map.
